# Flor Amarilla

Landing page estática sobre flores amarillas, hecha con HTML, CSS y JavaScript vanilla.

## Desarrollo local

Abre `index.html` en el navegador o levanta un servidor estático desde esta carpeta.

## Publicación

El workflow de `.github/workflows/pages.yml` publica automáticamente la carpeta raíz en GitHub Pages cada vez que se hace push a `main`.
